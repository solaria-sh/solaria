Solaria is a control plane for AI agent definitions. You declare an agent once: its instructions, model, tools, skills and sandbox. Solaria then plans and applies it to any host a provider supports, and records what it deployed where.

C. The three laws of Solaria

Agents do the work. These rules keep it honest.

Install SolariaRead the concepts
  1. First law

    A plan never surprises you.

    solaria plan diffs every field against recorded state before a host is touched.
  2. Second law

    An agent is the same agent wherever it runs.

    A content digest follows it to each host, so sha256:08ffaed7b158 in a container is the agent in the cloud.
  3. Third law

    What a host can't run never reaches it.

    Capability checks fail the plan early, and say which field the host can't take.
